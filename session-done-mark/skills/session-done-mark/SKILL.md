# セッションに【完了】を付ける

worktree・ブランチを残したまま、セッションが済んだことだけを印すためのスキル。
**タイトルを変える以外の操作は一切しない**（worktree・ブランチの削除、git 操作、Issue・PR の操作、
サイドバーの完了マークなどは行わない）。

## 手順

1. `get_session` ツール（`session_id: "self"`）で今のセッションタイトルを取得する。
   ツールが遅延読み込み（deferred）なら ToolSearch で
   `select:mcp__ccd_session_mgmt__get_session,mcp__ccd_session_mgmt__set_session_title` を読み込む。
2. タイトルが既に `【完了】` で始まっていれば変えずに、その旨を報告して終わる。
3. `set_session_title` ツール（`session_id: "self"`）で、`【完了】<今のタイトル>` に変える。
   - `【完了】` と元のタイトルの間に空白を入れない
   - 元のタイトルのそれ以外の部分は変えない
4. 変更後のタイトルを1行で報告する。

## ツールが無い環境（CLI 等）

タイトルを変えるツールが無いときは、次をそのまま実行できる形で提示する。

```
/rename 【完了】<今のタイトル>
```

今のタイトルが取得できなければ `<今のタイトル>` の部分をユーザーに埋めてもらう。

## 注意

- ユーザーが自分で付けたタイトルを変えるときは、アプリが承認を求めることがある。
  拒否されたら再試行せず、変えなかったことを報告する
- 「後片付け」と言われた場合はこのスキルではなく worktree-branch-cleanup を使う
  （そちらも最後に【完了】を付ける）
